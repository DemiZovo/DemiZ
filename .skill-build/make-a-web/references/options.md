# Website option catalog

Use this catalog to form a short, relevant questionnaire. Do not present every option unless the user requests a full comparison.

## Visual directions

- Minimal editorial: generous whitespace, restrained color, strong reading typography.
- Modern cards: modular cards, soft borders, moderate radii, compact summaries.
- Developer terminal: monospace accents, code-oriented details, dark-first palette.
- Warm personal: warmer neutrals, photography, informal typography and copy.
- Bold portfolio: large type, project imagery, expressive color and motion.
- Existing brand: derive tokens and components from supplied brand guidelines.

Confirm light, dark, or automatic theme behavior and whether motion should be static, subtle, or expressive.

## Page modules

- Home: identity, value proposition, selected content, primary calls to action.
- About: biography, experience, skills, values, contact links.
- Blog or notes: Markdown/MDX content, categories, tags, table of contents, related posts.
- Projects or case studies: curated local data, screenshots, repository/demo links, optional external metrics.
- Life, journal, or gallery: posts, images, captions, optional albums.
- Resume: web resume plus downloadable document.
- Contact: email/social links or a working form with delivery and spam controls.
- Legal: privacy, cookies, terms, licenses, attribution.

## Optional functions

- Drafts and scheduled publishing.
- Tags, categories, archives, pagination, and featured content.
- Local search or hosted search.
- RSS/Atom, Sitemap, robots.txt, canonical URLs, and social metadata.
- Light/dark/system theme switching.
- Syntax highlighting and copy-code controls.
- Analytics with opt-in configuration and privacy disclosure.
- Comments, reactions, newsletter signup, or guestbook through a selected service.
- CMS editing, authentication, localization, or database-backed content.
- Image optimization, responsive images, gallery lightbox, or media embeds.
- CI checks, preview deployments, production deployment, and link validation.

## Suggested default bundles

### Personal portfolio

Home, About, Projects, contact links, SEO, responsive images, Sitemap, and deployment automation.

### Technical blog

Home, Blog, Markdown/MDX, drafts, tags, archives, search, syntax highlighting, RSS, Sitemap, and deployment automation.

### Portfolio plus writing

Home, About, Projects, Blog, tags, search, RSS, SEO, theme switching, and deployment automation.

Defaults are conversation aids, not mandatory templates. Remove anything the user does not need.
